# Contributing to FreeCAD

FreeCAD is an open-source project and welcomes contributions from everyone.

## Ways to Contribute

- **Code**: Submit pull requests with bug fixes or new features.
- **Documentation**: Improve the wiki or handbook.
- **Translations**: Help translate FreeCAD.
- **Testing**: Report bugs and test new features.

## Getting Started

1. Read the [Developers Handbook](https://freecad.github.io/DevelopersHandbook).
2. Join the [FreeCAD forum](https://forum.freecadweb.org/) and [Discord](https://discord.gg/).
3. Fork the repository on GitHub.
4. Follow the coding guidelines.

## Pull Request Process

- Ensure your code passes existing tests.
- Add new tests if applicable.
- Update documentation.
- Submit the PR with a clear description.

For more details, see the [Contributing Guide](https://github.com/FreeCAD/FreeCAD/blob/master/CONTRIBUTING.md).
