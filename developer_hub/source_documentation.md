# Source Documentation

FreeCAD's source code is documented using Doxygen. The generated documentation is available at [SourceDoc](https://github.com/FreeCAD/SourceDoc).

- [Online Doxygen](https://freecad.github.io/SourceDoc/)

You can also build the documentation locally:

```bash
cd build
doxygen ../Doc/FreeCAD_doxygen.in
```

For API reference, see the [FreeCAD API documentation](https://wiki.freecadweb.org/FreeCAD_API).
