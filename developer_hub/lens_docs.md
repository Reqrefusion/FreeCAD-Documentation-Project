# Lens Docs

The [Lens Docs](https://github.com/FreeCAD/lens-docs) repository contains documentation for the FreeCAD Lens (a build-once-document-anywhere tool).

## Usage

- Install the tool as described in the [Lens Docs README](https://github.com/FreeCAD/lens-docs).
- Write documentation in Markdown or reStructuredText.
- Build and publish.

For more information, visit the [repository](https://github.com/FreeCAD/lens-docs).
