# Addon Development

FreeCAD supports addons (workbenches and macros) written in Python. The [Addon Academy](https://github.com/FreeCAD/Addon-Academy) provides tutorials and templates.

## Getting Started

- Read the [Addon Academy](https://github.com/FreeCAD/Addon-Academy) documentation.
- Check out examples in the [FreeCAD-addons](https://github.com/FreeCAD/FreeCAD-addons) repository.
- Use the [FreeCAD module](https://wiki.freecadweb.org/FreeCAD_API) for Python.

## Publishing Addons

- Host your addon on GitHub.
- Add a `package.xml` metadata file.
- Create a PR to the [FreeCAD-addons](https://github.com/FreeCAD/FreeCAD-addons) repository.

For more info, see the [Addon Development Guide](https://wiki.freecadweb.org/Addon).
