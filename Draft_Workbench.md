# Draft Workbench

The Draft Workbench is a comprehensive toolset for 2D drafting and 3D modeling. It has been significantly enhanced with new features introduced in recent FreeCAD versions. This page lists the additions and modifications that have been made.

## New Features

- **AnnotationStyleEditor**: A new tool to create and manage annotation styles (dimensions, texts, etc.). See [Draft AnnotationStyleEditor](Draft_AnnotationStyleEditor.md).
- **SetStyle**: Allows applying a saved style to selected objects. See [Draft SetStyle](Draft_SetStyle.md).
- **Snap improvements**: Added snap to midpoint, perpendicular, and extension points. See [Draft Snap](Draft_Snap.md).
- **Layer management**: Layers now support groups and better property inheritance. See [Draft Layer](Draft_Layer.md).

## Updated Commands

- **Draft Dimension**: Now supports annotation styles.
- **Draft Text**: Can be linked to annotation styles.
- **Draft Wire**: Improved point selection with new snap modes.

For a complete list of commands, see [Draft Module](Draft_Module.md).
