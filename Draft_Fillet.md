== Description ==
The '''Draft Fillet''' command creates a fillet (rounded corner) or a chamfer between two selected edges. The edges must be part of a [Draft_Wire](Draft_Wire.md) or [Draft_BSpline](Draft_BSpline.md) that is closed or has at least two edges. It is available in the {{VersionPlusLink|0.21}}.

== Usage ==
# Select two edges of the same wire that meet at a vertex.
# There are several ways to invoke the command:
#* Press the **Fillet** button.
#* Select the **Draft → Fillet** option from the menu.
#* Use the keyboard shortcut: **F** then **I**.
# The task panel opens. See [Options](#Options) for more information.
# Pick a fillet radius or a chamfer distance.
# Press **OK** to create the fillet.

== Options ==
* Press **Esc** or the **Cancel** button to abort the command.
* **Radius**: The radius of the fillet. A value of 0 creates a chamfer.
* **Trim**: If checked, the original edges are trimmed to the fillet endpoints.
* **Delete original**: If checked and the fillet creates a closed wire, the original wire is deleted.

== Properties ==
See also: [Property editor](Property_editor.md).

A Draft Fillet object shares most properties with a [Draft Wire](Draft_Wire.md). The following properties are additional:

* Data{{PropertyData|Fillet Radius}}: The radius of the fillet.
* Data{{PropertyData|Chamfer}}: If true, a chamfer is created instead of a fillet.

== Scripting ==
See also: [Autogenerated API documentation](https://freecad.github.io/SourceDoc/) and [FreeCAD Scripting Basics](FreeCAD_Scripting_Basics.md).

To create a Draft Fillet use the `make_fillet` method of the Draft module:

```python
import Draft

# Create a wire
wire = Draft.make_wire([App.Vector(0,0,0), App.Vector(0,10,0), App.Vector(10,10,0), App.Vector(10,0,0)])

# Fillet the first two edges with radius 2
fillet = Draft.make_fillet(wire, radius=2, chamfer=False, trim=True, delete=False)
```
