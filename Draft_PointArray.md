## Description

The PointArray tool creates an array of copies of a selected object at the positions of points from a point compound. The point compound can be a Draft Point, a Part Vertex, or any shape with vertices.

## Usage

1. Select the object to duplicate.
2. Select the point compound.
3. Press the **Draft PointArray** button, or use the **Draft → Array tools → Point array** menu.
4. The array is created.

## Options

- The array is parametric. Changing the object or the point compound updates the array.
- Use the **Fuse** property to fuse the copies into one shape.

## Properties

- **Base**: The object to duplicate.
- **Point Compound**: The compound holding the points.
- **Fuse**: If true, the copies are fused into a single shape.
