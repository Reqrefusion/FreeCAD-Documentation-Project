# Draft Layer

## Description

The **Draft Layer** command creates a layer container to organize objects and control their visibility and appearance.

## Usage

1. Press the **Draft Layer** button or use the menu **Draft → Utilities → Layer**.
2. A new layer is added to the document.
3. Drag objects into the layer in the Tree view.
4. Adjust layer properties in the Property editor (color, line width, visibility).

## Properties

- **Base**: Inherits App::FeaturePython properties.
- **Layer**: Contains group management.
- **Appearance**: Override line color, line width, shape color.

## Notes

- Layers can contain any document object.
- Layers are nestable.
- A toggle button in the toolbar allows quick visibility control.
