# Draft Snap WorkingPlane

## Description

The **Draft Snap WorkingPlane** option snaps to intersections of an imaginary grid on the current working plane.

## Usage

1. Ensure snapping is enabled.
2. Enable **Draft Snap WorkingPlane** in the snap toolbar.
3. When near a grid intersection, the snap point is highlighted.

## Notes

- Only works if the working plane is set (visible grid).
- Combine with other snap modes.
