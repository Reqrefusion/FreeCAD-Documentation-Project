# Addon Development

Learn how to create addons for FreeCAD using the [Addon Academy](https://github.com/FreeCAD/Addon-Academy).

## Getting Started
1. Clone the Addon Academy repository: `git clone https://github.com/FreeCAD/Addon-Academy.git`
2. Follow the tutorials in `tutorials/` for creating your first addon.
3. Use the [Addon Manager](https://wiki.freecadweb.org/Addon_Manager) for testing.

## Best Practices
- Use Python and Qt for UI (or C++ for extensions).
- Follow the [Addon Structure Guide](https://github.com/FreeCAD/Addon-Academy/blob/master/structure.md).
- Include tests and documentation.
- Submit your addon to the [FreeCAD Addons](https://github.com/FreeCAD/FreeCAD-addons) repository.
