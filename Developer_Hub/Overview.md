# FreeCAD Developer Hub

Welcome to the central resource for FreeCAD developers. This hub consolidates all essential developer information, from building FreeCAD to contributing code, creating addons, and understanding the internals.

## Key Resources

- **[Developers Handbook](https://freecad.github.io/DevelopersHandbook)**: Comprehensive guide for new and existing developers. Covers build setup, architecture, contributing guidelines, and more.
- **[Addon Academy](https://github.com/FreeCAD/Addon-Academy)**: Tutorials and best practices for creating FreeCAD addons, including packaging, testing, and distribution.
- **[Source Documentation](https://github.com/FreeCAD/SourceDoc)**: Doxygen-generated API documentation for the FreeCAD source code.
- **[Lens Docs](https://github.com/FreeCAD/lens-docs)**: Documentation for the FreeCAD lens system, including custom lens creation.

## Contribution Workflow
1. Fork the [FreeCAD repository](https://github.com/FreeCAD/FreeCAD).
2. Create a feature branch from `master`.
3. Make your changes following the [coding standards](https://freecad.github.io/DevelopersHandbook/coding_standards/).
4. Submit a pull request and ensure CI passes.

## Development Tools
- **Build System**: CMake with Qt5/6 support.
- **Debugging**: See [Debugging FreeCAD](https://freecad.github.io/DevelopersHandbook/debugging/).
- **Testing**: Unit tests with QTest; integration tests with PyTest.
