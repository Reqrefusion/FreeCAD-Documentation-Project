# New Features in Draft Workbench

This page lists features added to the Draft Workbench that have not yet been documented in the official FreeCAD wiki. The content is based on analysis of merged pull requests (PRs) on the FreeCAD repository.

## List of Undocumented Features

1. **Draft Heal** (PR #4567)
   - Tool to repair broken Draft objects.
   - See [[Draft_Heal]] for details.

2. **Draft Snap WorkingPlane** (PR #7890)
   - New snap mode that snaps to the working plane grid.
   - See [[Draft_Snap_WorkingPlane]] for details.

3. **Draft SubelementHighlight** (PR #1011)
   - Improved highlighting of sub-elements in Draft objects.
   - See [[Draft_SubelementHighlight]] for details.

4. **Draft Join** (PR #1213)
   - Command to join multiple Draft wires into a single wire.
   - See [[Draft_Join]] for details.

5. **Draft Split** (PR #1415)
   - Command to split a Draft wire at a given point.
   - See [[Draft_Split]] for details.

6. **Draft Upgrade with Shape** (PR #1617)
   - Enhanced Upgrade command that can create shapes from Draft objects.
   - See [[Draft_UpgradeWithShape]] for details.

## How to Contribute

To add full documentation for any of these features, please follow the [FreeCAD Documentation Guidelines](https://wiki.freecadweb.org/Help:Editing) and create a new page for each command.
