# New Features in Draft Workbench

This document summarizes new features recently added to the Draft Workbench via pull requests. These features are now included in the documentation.

## Snap Enhancements
- **Snap to Perpendicular**: Added ability to snap to perpendicular points on edges.
- **Snap to Parallel**: Snap to lines parallel to a selected edge.
- **Snap to Extension**: Snap to imaginary extensions of edges.

## Layer Management
- **Draft LayerManager**: New tool to organize objects into layers with visibility and color controls.
- **Layer Presets**: Save and load layer configurations.

## Annotation Improvements
- **Draft AnnotationStyleEditor**: Edit text styles for dimensions and labels.
- **Draft ShapeString**: Enhanced font support and alignment options.

## Working Plane Proxy
- **Draft WorkingPlaneProxy**: Save and restore working plane orientations for multiple views.

## Grid and Axis
- **Draft ToggleGrid**: Improved grid display with customizable spacing and visibility by layer.
- **Draft Axis**: New axis system for parametric constraints.

## Additional Tools
- **Draft SubelementHighlight**: Highlight subelements like edges and faces for selection.
- **Draft Facebinder**: Create a face binder from selected faces.

These features are now documented in their respective command pages. See the Draft Workbench documentation for full details.
