# Draft Snap

The Draft Workbench provides a set of snap tools to help you pick precise points. Recent additions include new snap modes.

## Snap Modes

| Icon | Command | Description |
|------|---------|-------------|
| ![Snap Midpoint](Snap_Midpoint.svg) | **Snap Midpoint** | Snaps to the midpoint of edges. |
| ![Snap Perpendicular](Snap_Perpendicular.svg) | **Snap Perpendicular** | Snaps to the perpendicular foot on edges. |
| ![Snap Extension](Snap_Extension.svg) | **Snap Extension** | Snaps to the extension of lines or edges. |
| ![Snap Intersection](Snap_Intersection.svg) | **Snap Intersection** | Snaps to intersections of edges. (Existing) |
| ... | ... | ... |

## Usage

Enable desired snap modes by clicking their toolbar buttons. When a snap mode is active, the cursor will highlight when near a snap point.

## Preferences

Snap settings can be adjusted in **Preferences → Draft → Grid and snapping**.
