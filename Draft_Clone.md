## Description

The Clone tool creates a clone (linked copy) of a selected object. The clone is parametric and will update if the original object changes.

## Usage

1. Select the object to clone.
2. Press the **Draft Clone** button, or use the **Draft → Utilities → Clone** menu.
3. A clone is created at the same position.

## Options

- The clone has the same placement as the original. Use **Draft Move** to reposition.
- The clone can be scaled by setting its **Scale** property.

## Properties

- **Base**: The original object.
- **Scale**: Vector scale factor.
