# Draft Annotation

## Description

The **Draft Annotation** command creates a text annotation with a leader line.

## Usage

1. Press the **Draft Annotation** button or use the menu **Draft → Annotation → Annotation**.
2. Pick a point for the text.
3. Optionally pick additional points for the leader line (press **Enter** to finish).
4. Enter text in the dialog.

## Options

- **Text**: Multi-line text.
- **Font size**: Set in Property editor.
- **Color**: Inherits from layer or override.

## Notes

- The annotation is a Draft Text plus a Draft Wire leader.
- Double-click on the annotation to edit text.
- Supports text formatting.
