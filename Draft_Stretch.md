# Draft Stretch

## Description

The **Draft Stretch** command stretches objects by moving selected vertices/edges.

## Usage

1. Select objects to stretch.
2. Press the **Draft Stretch** button or use the menu **Draft → Modify → Stretch**.
3. Pick base point.
4. Pick target point.

## Notes

- Only Draft Wires, Lines, BSplines, and Draft Points are supported.
- You can also stretch edges by selecting them individually.

## Options

- Press **Shift** to constrain movement horizontally or vertically.
- Press **Ctrl** to snap.
