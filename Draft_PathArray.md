## Description

The PathArray tool creates an array of copies of a selected object along a selected path. The path can be any edge or wire.

## Usage

1. Select the object to duplicate.
2. Select the path object.
3. Press the **Draft PathArray** button, or use the **Draft → Array tools → Path array** menu.
4. The array is created.

## Options

- **Count**: Number of copies.
- **Align**: If true, the copies are aligned to the tangent of the path.
- **Fuse**: If true, the copies are fused into one shape.

## Properties

- **Base**: The object to duplicate.
- **Path**: The path object.
- **Count**: Number of copies.
- **Align**: Boolean for alignment.
- **Fuse**: Boolean for fusing.
